# ET-CAM Website

Ethiopian Creative Advertisement Media - Digital Marketing Agency Website

## Overview

A single-page, multi-section marketing website for ET-CAM, a digital marketing agency based in Addis Ababa, Ethiopia. The site features:

- **Dark/Light Theme Toggle** - Switch between Dark Luxury and Neo Minimal themes
- **Language Toggle** - Switch between English and Amharic
- **Fully Responsive** - Optimized for mobile, tablet, and desktop
- **No Framework Dependencies** - Pure HTML, CSS, and JavaScript
